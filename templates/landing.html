Frequently Asked Questions

Got Questions?

Does this demo require an external API key or paid subscription?

No. This interactive demo operates completely inside your web browser using simulated generation logic and localStorage persistence. No API key, credit card, or external backend is needed.

Can I add my own articles and test real generation?

Yes! You can paste in your own text or import `.txt` files in the Source Library, and generate customized social posts tailored to each platform.

How does ContentFlow AI export approved posts?

You can export approved posts or draft queues directly to CSV or JSON format using browser Blob APIs, complete with formula injection protection.
